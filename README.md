# AgentLocal — лендинг

Статический лендинг: чистый HTML + CSS + JS, без сборки и зависимостей.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка и весь текст (RU и EN в `data-ru` / `data-en`) |
| `style.css` | Стили, токены дизайна в `:root`, адаптив |
| `script.js` | Переключатель языка, меню, анимации появления, форма |

## Как открыть

Просто двойной клик по `index.html` — всё работает локально.

## Как редактировать тексты

Каждый переводимый элемент несёт два атрибута:

```html
<h3 data-ru="Автосервисы" data-en="Auto services">Автосервисы</h3>
```

Правьте `data-ru` и `data-en` — содержимое тега подставляется скриптом при выборе языка.
Для плейсхолдеров полей используются `data-ru-ph` / `data-en-ph`.

Выбранный язык сохраняется в `localStorage`; при первом заходе определяется по языку браузера.

## Как поменять цвета и типографику

Всё в начале `style.css`:

```css
:root{
  --accent:   #4f46e5;   /* основной акцент */
  --accent-2: #06b6d4;   /* второй цвет градиента */
  --ink:      #0a0c14;   /* текст */
  --bg-soft:  #f6f7fb;   /* фон чередующихся секций */
  --font-display:'Unbounded', ...;  /* заголовки */
  --font-body:'Manrope', ...;       /* текст */
}
```

## Форма заявки

Заявки уходят через [Web3Forms](https://web3forms.com) — бесплатно до 250 писем в месяц,
регистрация не нужна, почта не светится в исходниках страницы.

**Подключение:**

1. На web3forms.com введите почту, куда должны приходить заявки — ключ придёт письмом.
2. В `index.html` найдите `ЗАМЕНИТЕ-НА-ACCESS-KEY` и вставьте ключ вместо него.

Что собирает форма: имя, телефон, Telegram, сферу бизнеса, комментарий и согласие на
обработку данных. Плюс скрытое поле `botcheck` — ловушка для спам-ботов: если она
заполнена, отправка молча отменяется.

Пока ключ не вставлен, форма честно пишет «не подключена» вместо того, чтобы делать вид,
что заявка ушла.

Логика отправки — в `script.js`, блок `5. Demo form → Web3Forms`. Тексты сообщений об
ошибках и успехе лежат в объекте `NOTES` в начале файла, на обоих языках.

## Контакты в Telegram

Ссылки прописаны в трёх местах `index.html` — секция `id="contacts"`, футер и `contact-strip`.
Ищите `t.me/` и меняйте на свои аккаунты (сейчас там `agentlocal_sales`, `agentlocal_support`,
`agentlocal_ceo`). Не забудьте про подписи `@agentlocal_...` рядом со ссылками.

## Сборка одного файла

```bash
powershell -ExecutionPolicy Bypass -File build.ps1
```

Собирает `dist\agentlocal.html` — весь лендинг в одном файле: CSS, JS и шрифты (Manrope и
Unbounded) вшиты как data-URI. Такой файл работает без интернета и его удобно куда угодно закинуть.
Запускайте заново после правок текста или стилей.

> Файл `build.ps1` сохранён в UTF-8 **с BOM** — иначе PowerShell 5.1 читает кириллицу как ANSI
> и падает с ошибкой парсинга. Если правите его редактором, сохраните кодировку.

## Деплой на Vercel

```bash
npx vercel --prod
```

Либо загрузите папку через веб-интерфейс Vercel: framework — **Other**, build command не нужен,
output directory — корень проекта. Так же работает Netlify (drag & drop папки) и GitHub Pages.
