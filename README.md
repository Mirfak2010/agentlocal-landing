# Rezaru — лендинг

Статический лендинг: чистый HTML + CSS + JS, без сборки и зависимостей.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка и весь текст (RU и EN в `data-ru` / `data-en`) |
| `style.css` | Стили, токены дизайна в `:root`, адаптив |
| `script.js` | Переключатель языка, меню, анимации появления, форма |

## Как открыть

Просто двойной клик по `index.html` — всё работает локально.

## Как редактировать тексты

Каждый переводимый элемент несёт два атрибута:

```html
<h3 data-ru="Автосервисы" data-en="Auto services">Автосервисы</h3>
```

Правьте `data-ru` и `data-en` — содержимое тега подставляется скриптом при выборе языка.
Для плейсхолдеров полей используются `data-ru-ph` / `data-en-ph`.

Выбранный язык сохраняется в `localStorage`; при первом заходе определяется по языку браузера.

## Как поменять цвета и типографику

Всё в начале `style.css`:

```css
:root{
  --ink:        #f5f2ed;   /* off-white — основной текст */
  --bg:         #0b0b0b;   /* noir — фон страницы */
  --bg-soft:    #100d0e;   /* чередующиеся секции */
  --surface:    #151011;   /* карточки */
  --surface-2:  #1c1517;   /* приподнятые элементы */
  --line:       #2c2124;   /* границы */
  --accent:     #a11024;   /* багровый — заливки */
  --accent-2:   #5c0512;   /* бордо — конец градиента */
  --accent-lite:#e0475a;   /* светлый багровый — текст и иконки */
  --font-display:'Unbounded', ...;  /* заголовки */
  --font-body:'Manrope', ...;       /* текст */
}
```

Важное правило — **для текста и иконок берите `--accent-lite`, а не `--accent`**. Это один и
тот же багровый, но подобранный под фон темы: на чёрном он светлее (`#e0475a`), на креме
остаётся глубоким (`#8b0d1a`). `--accent` нужен только для заливок, градиентов и теней.

## Две темы

Тёмная (чёрный + багровый) и светлая (кремовая) переключаются кнопкой в шапке. Выбор
сохраняется в `localStorage`; при первом заходе берётся настройка системы
(`prefers-color-scheme`) — так же, как с языком.

Светлая тема — это блок `:root[data-theme="light"]` в `style.css`, где переопределяются
те же токены:

```css
:root[data-theme="light"]{
  --ink:  #3e000c;   /* chocolate */
  --bg:   #ffecd1;   /* sand — кремовая основа */
  --accent-lite: #8b0d1a;
  ...
}
```

**Добавляете новый цвет — заводите токен и переопределяйте его в обеих темах.** Жёстко
зашитый цвет сломает одну из тем.

Исключение — `--on-accent` (`#f5f2ed`): текст на багровых заливках должен оставаться светлым
всегда, поэтому в светлой теме он не переопределяется. Иначе надписи на кнопках стали бы
тёмными на тёмно-красном.

## Форма заявки

Заявка уходит в Telegram. Посетитель заполняет поля, нажимает кнопку — открывается чат
с готовым текстом, остаётся нажать «Отправить». Сторонних сервисов, регистраций и почты
в коде нет, ломаться нечему.

Получатель задан в `script.js` (без `@`):

```js
const TELEGRAM_TARGET = 'mirfak_0';
```

Собирается сообщение вида:

```
Заявка с сайта Rezaru

Имя: Иван
Телефон: +7 900 123-45-67
Telegram: @ivan
Сфера: Автосервис
Задача: принимать звонки вечером
```

Пустые необязательные поля в сообщение не попадают. Подписи строк переключаются вместе
с языком сайта — они лежат в объекте `NOTES` в начале `script.js` (ключи `title`, `fName`,
`fPhone`, `fTelegram`, `fBusiness`, `fMessage`), там же тексты ошибок валидации.

Обязательны только имя и телефон: имя от двух символов, в телефоне минимум 10 цифр.

**Ограничение способа.** Заявка отправляется руками посетителя из его же Telegram — если он
передумает и не нажмёт «Отправить», вы её не увидите. Взамен: ничего не нужно активировать,
заявки приходят мгновенно в телефон, а почта не светится в публичном репозитории.

Логика — в `script.js`, блок `5. Demo form → Telegram`.

## Контакты в Telegram

Сейчас на сайте два аккаунта — `@mirfak_0` (подключение и демо) и `@Mr_tt52` (вопросы и
поддержка). Ссылки прописаны в двух местах `index.html`: секция `id="contacts"` и футер.
Ищите `t.me/` — рядом со ссылкой всегда идёт подпись `@...`, её тоже нужно поменять.

Публичной почты на сайте нет намеренно — все обращения идут в Telegram. Если понадобится,
добавьте карточку с `mailto:` в секцию контактов.

Форма отправляет заявку в `@mirfak_0` (константа `TELEGRAM_TARGET`). Чтобы заявки уходили
на другой аккаунт, поменяйте только её — карточки контактов при этом не затрагиваются.

## Кеш браузера

CSS и JS подключены с версией: `style.css?v=2`, `script.js?v=2`.

**После правки стилей или скрипта увеличивайте номер** в `index.html` — иначе посетители
с уже открытым сайтом продолжат видеть старую версию. GitHub Pages отдаёт файлы с
`Cache-Control: max-age=600`, и браузер держит их даже дольше; смена адреса заставляет
скачать заново.

## Сборка одного файла

```bash
powershell -ExecutionPolicy Bypass -File build.ps1
```

Собирает `dist\rezaru.html` — весь лендинг в одном файле: CSS, JS и шрифты (Manrope и
Unbounded) вшиты как data-URI. Такой файл работает без интернета и его удобно куда угодно закинуть.
Запускайте заново после правок текста или стилей.

> Файл `build.ps1` сохранён в UTF-8 **с BOM** — иначе PowerShell 5.1 читает кириллицу как ANSI
> и падает с ошибкой парсинга. Если правите его редактором, сохраните кодировку.

## Деплой на Vercel

```bash
npx vercel --prod
```

Либо загрузите папку через веб-интерфейс Vercel: framework — **Other**, build command не нужен,
output directory — корень проекта. Так же работает Netlify (drag & drop папки) и GitHub Pages.
